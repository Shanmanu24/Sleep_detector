NIGHTWATCH — Browser Demo

Client-side preview of the Sleep Detecting System UI

SYSTEM ARMED
What this page is: a browser-only preview so you can test the UI and alarm right now from a link, using your webcam and zero installs. It uses a simple brightness heuristic (no ML model download) to approximate eye closure — good enough to see the system react, but less accurate than the real thing. The full version — MediaPipe eye-landmark tracking with a Python/Flask backend — is in the downloadable project; it has to run on your own machine because it needs direct access to a webcam, which a hosted page can't provide on its own.
